# e-bike-power-station

# 🔋 48V E-Bike Battery to Portable Power Station

This repository contains a complete build blueprint for converting a long-case 48V e-bike battery into a portable power station, plus a picture-first assembly guide for documenting the build.

## Repository Layout

```text
├── README.md
├── docs/
│   ├── 1_hardware_BOM.md
│   ├── 2_schematics.md
│   └── 3_assembly_guide.md
└── assets/
    └── images/
```

## Quick Start

1. Read `/home/runner/work/e-bike-power-station/e-bike-power-station/docs/1_hardware_BOM.md`
2. Review wiring and power limits in `/home/runner/work/e-bike-power-station/e-bike-power-station/docs/2_schematics.md`
3. Follow the picture guide in `/home/runner/work/e-bike-power-station/e-bike-power-station/docs/3_assembly_guide.md`
4. Add your build photos to `/home/runner/work/e-bike-power-station/e-bike-power-station/assets/images/`

## Critical Safety Limit

With a 51.2V nominal battery and 30A ANL fuse, total simultaneous system load should remain at or below **~1,500W**.
